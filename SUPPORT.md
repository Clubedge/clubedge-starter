# Getting help

- For installation and provider configuration, start with [SETUP.md](SETUP.md).
- For defects, search existing issues and then open a bug report using the repository issue form.
- For improvements, open a feature request or a discussion issue describing the use case before starting a large change.
- For security vulnerabilities, use the private process in [SECURITY.md](SECURITY.md); do not post exploit details publicly.

This is a community-maintained starter project. It does not currently offer paid support or response-time guarantees.
